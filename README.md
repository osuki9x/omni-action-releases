# Omni Action

**Visual automation for the work you repeat.**

Omni Action turns commands, keys, mouse actions, text, timing, and captured
interface targets into readable visual macros. Trigger them with a shortcut or
from a customizable radial menu. Version 3.1 includes the current public
integration for DaVinci Resolve on macOS.

Visit the official homepage for the product tour, installation options, and
requirements:

**[osuki9x.github.io/omni-action-releases](https://osuki9x.github.io/omni-action-releases/)**

## Install

Choose the guided Apple Shortcut on the homepage, or run:

```bash
/bin/bash -c "$(curl -fsSL https://github.com/osuki9x/omni-action-releases/releases/latest/download/install.sh)"
```

The installer verifies the signed release before installation and preserves
existing Omni Action macros, radial menus, presets, triggers, and settings.

This public repository hosts the official website and signed release assets.
