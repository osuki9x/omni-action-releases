GOOD TO KNOW

Questions,
answered.

Everything you need before your first macro.

What does Omni Action automate?

Version 3.1 focuses on DaVinci Resolve. A macro can combine app commands, keyboard input, mouse actions, text, timing, repeat logic, and captured interface targets into one reusable action.

Do I need to write code?

No. The Builder is visual and covers the normal workflow. Advanced users can optionally edit or share a macro as JSON.

Why does Omni Action need Accessibility access?

macOS requires Accessibility permission before Hammerspoon can inspect and control interface elements. The installer guides you to the correct setting; Omni Action cannot bypass it.

Will an update remove my macros or presets?

No. User content and settings live outside the replaceable app package. The installer preserves them and backs up the previous package during an update.

How do I open the Builder?

The installer opens it when setup finishes. Afterwards, use the Omni Action Builder shortcut configured by the app, or open it from Hammerspoon.
