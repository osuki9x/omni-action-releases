Building blocks

App Command

Choose a command supplied by the active integration.

Silent Action

Press a captured interface control without moving the cursor.

Keyboard

Send a key or key combination.

Pause

Wait when the interface needs time to catch up.

Input

Enter text or a value into a captured field.

Mouse

Move, click, or drag at a control or screen point.

GOOD TO KNOW

Before you install.

Short answers to the questions that affect setup and daily use.

What can Omni Action automate today?

Version 3.1 supports DaVinci Resolve. A macro can combine app commands, keys, text, timing, mouse actions, repeat logic, and captured interface targets.

Is Omni Action only for DaVinci Resolve?

DaVinci Resolve is the current public integration, not the limit of the product. Omni Action uses a shared Builder and an integration layer so support for another app can be added later.

Do I need to write code?

No. Normal setup and editing happen in the visual Builder. Editing or sharing a macro as JSON is optional.

Why does it need Accessibility access?

macOS requires this permission before Hammerspoon can inspect and control interface elements. The installer opens the correct setting.

Will an update remove my macros or presets?

No. User content lives outside the replaceable app package. The installer preserves it and backs up the previous package.

What gets installed?

Omni Action runs as a Hammerspoon Spoon. The Terminal method can install Hammerspoon for you; the Shortcut method expects it to be available before setup finishes.
